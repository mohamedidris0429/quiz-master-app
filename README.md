# 🌟 QuizMaster Pro - Glassmorphic Quiz Application

A sleek, responsive, and interactive mobile quiz application crafted with an ultra-modern **Glassmorphism UI**. Designed as part of the internship task to deliver an intuitive user experience with category-based progression and multi-level challenges.

---

## ✨ Features

- **Modern Glassmorphism UI:** Frosted glass panels, vibrant glowing ambient gradients, and fluid micro-interactions.
- **Categorized Question Bank:** 
  - 🌍 Socialism & Society
  - 🎮 Games & Esports
  - 💻 Tech & Coding
  - 💡 General Knowledge
- **Level-Based Progression:** Modular question structure divided across multiple difficulty levels.
- **Instant Visual Feedback:** Color-coded correct/incorrect state highlighting with automatic score calculation.
- **Lightweight & Cross-Platform:** Built with zero heavy dependencies (pure HTML5, CSS3, and Vanilla JavaScript), making it ideal for Web, WebView, and Android APK deployment.
- **Integrated Vector Branding:** Built-in lightweight SVG logo for crisp rendering on any screen density.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Backdrop-Filter), Vanilla JavaScript
- **Mobile Framework Integration:** Capacitor / Android WebView
- **Typography:** Google Poppins
